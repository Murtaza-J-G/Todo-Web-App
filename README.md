# ✅ Todo App

A simple, modern, and user-friendly **Todo App** designed to help users organize tasks, manage daily activities, and stay productive. The application features **Light and Dark themes**, allowing users to choose their preferred appearance for a comfortable experience.

## ✨ Features

- 📝 **Task Management:** Add, edit, and delete tasks.
- ✅ **Task Completion:** Mark tasks as completed or pending.
- 🌗 **Light and Dark Themes:** Switch between light and dark modes.
- 🎨 **Modern UI:** Clean and responsive user interface.
- 📱 **Responsive Design:** Use the application on different screen sizes.

## 🎯 Project Goal

The goal of this project is to provide a simple and effective tool for managing daily tasks, improving productivity, and offering a personalized user experience through theme customization.
